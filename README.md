# 🔐 Account Verification Webpage

## 📌 Description

A simple front-end project that demonstrates an account verification interface using **HTML, CSS, and JavaScript**.
It allows users to enter their name and displays a dynamic verification message upon clicking the sign-in button.

---

## 🚀 Features

* User input field for name and password
* Interactive **Sign In** button
* Dynamic greeting message using JavaScript
* Beginner-friendly project structure

---

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

---

## 💡 How It Works

1. User enters their name
2. Clicks the **Sign In** button
3. JavaScript captures the input
4. Displays a message like:

   ```
   Hi [username], verifying your account...
   ```
